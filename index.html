常见问题

常见问题

HTML 不是更消耗 Token 吗？
虽然 HTML 通常使用更多 Token，但 Opus 4.7 拥有 1M 上下文窗口，增加的 Token 用量几乎可以忽略。而且 HTML 更高的表达力意味着你更可能真正去阅读它——整体产出质量更好。
你现在什么时候还用 Markdown？
作者坦言几乎在所有场景都停止使用 Markdown 了。他可能处于 HTML 极端主义者的位置，但对于 AI Agent 输出来说，HTML 确实全面占优。
怎么查看 HTML 文件？
直接在浏览器中打开本地文件即可（可以让 Claude 帮你 open）。如果需要分享，上传到 S3 或任何静态托管就能获得可访问的链接。
生成时间不是更长吗？
是的，HTML 生成可能比 Markdown 慢 2-4 倍。但考虑到结果的质量提升、可读性改善和交互能力，这些额外时间是完全值得的投入。
版本控制怎么办？
这确实是 HTML 最大的缺点之一。HTML 的 diff 比较嘈杂且难以审查，不如 Markdown 干净。对于需要频繁 diff 的场景，需要权衡这个取舍。
如何让 Claude 生成的 HTML 符合我的风格？
使用 frontend-design skill 可以帮助 Claude 生成更好的 HTML。如果需要匹配公司风格，可以让 Claude 读取你的代码库，创建一个设计系统 HTML 文件作为后续参考。

使用 HTML 让我感到自己更加深入地参与了与 Claude 的协作循环。我曾经担心自己不再深入阅读计划就意味着不得不完全放权给 Claude——但 HTML 让我比以往任何时候都更加「在环」。
